# 방 생성 설정 — v2

## 어떻게 설정하나요?

1. 시작 인원(4~12명)을 선택합니다. 이 인원이 방 정원이기도 합니다.
2. 마피아·경찰·의사·일반 시민의 인원을 지정합니다.
3. 낮 토론·투표·밤 행동 시간을 초 단위 정수로 입력합니다.
4. 유효한 설정이면 방을 만들 수 있습니다. 대기실에서 모두가 확정 설정을 확인할 수 있습니다.
5. 설정 인원 전원이 모이고 방장 외 모두 준비해야 시작됩니다.

시작 인원을 바꾸면 역할은 새 인원의 권장 구성으로 초기화됩니다. 시간은 유지합니다.
마피아·경찰·의사를 바꾸면 남은 자리를 일반 시민으로 자동 계산합니다.
일반 시민을 직접 입력할 수도 있으며, 최종 역할 합계가 시작 인원과 다르면 생성을 막습니다.
`권장 구성으로 맞추기`로 역할을 기본값으로 돌릴 수 있습니다.
설정은 방 생성 시 확정되며 이번 버전에는 생성 후 설정 변경 기능은 없습니다.
재경기는 같은 설정을 유지합니다.

## 역할 최대치

| 시작 인원 | 마피아 범위 | 경찰 범위 | 의사 범위 | 기본 구성: 마피아/경찰/의사/시민 |
| --- | --- | --- | --- | --- |
| 4 | 1 | 0~1 | 0~1 | 1/1/1/1 |
| 5 | 1 | 0~1 | 0~1 | 1/1/1/2 |
| 6 | 1 | 0~1 | 0~1 | 1/1/1/3 |
| 7 | 1~2 | 0~1 | 0~1 | 2/1/1/3 |
| 8 | 1~2 | 0~1 | 0~2 | 2/1/1/4 |
| 9 | 1~2 | 0~1 | 0~2 | 2/1/1/5 |
| 10 | 1~3 | 0~2 | 0~2 | 3/1/1/5 |
| 11 | 1~3 | 0~2 | 0~2 | 3/1/1/6 |
| 12 | 1~3 | 0~2 | 0~2 | 3/1/1/7 |

추가 조건:

- 일반 시민 최소 1명
- 역할 합계 = 시작 인원
- 경찰 + 의사 ≤ 설정한 마피아 수 + 1

표의 개별 최대치를 모두 동시에 사용할 수 있다는 뜻은 아닙니다.
예를 들어 10인이라도 마피아 1명일 때 경찰 2명+의사 2명은 허용하지 않습니다.
마피아 수를 올리거나 특수직업을 줄여 합계 제한을 맞춰야 합니다.

이것은 소규모 방에서 마피아·특수직업 과밀을 막기 위한 초기 정책입니다.
실측 승률로 균형을 보증하는 공식은 아니며, 플레이 결과에 따라 engine.py의 balance_limits와 합계 제한을 조정할 수 있습니다.

## 시간

| 단계 | 허용 범위 | 기본 |
| --- | --- | --- |
| 낮 토론 | 30~300초 | 90초 |
| 투표 | 15~120초 | 30초 |
| 밤 행동 | 15~120초 | 30초 |

범위 안에서 47초·19초처럼 정수 단위로 자유롭게 입력할 수 있습니다.
서버가 이 시간을 마감 시각 계산에 사용합니다. 재접속 대기 중에는 기존과 같이 시간을 보상합니다.

## 설정 예시

8인: 마피아 2 / 경찰 1 / 의사 2 / 시민 3, 토론 120초 / 투표 45초 / 밤 40초.
마피아 2명의 특수직업 허용 합계는 3명이므로 경찰 1+의사 2가 가능합니다.
게임 시작 시 실제로 해당 구성으로 무작위 배정하며 각 단계는 120/45/40초로 진행됩니다.

## 기존 버전 업데이트

진행 중인 게임을 마친 뒤 ZIP의 소스 파일을 기존 프로젝트 폴더에 덮어쓰세요.
실제 .env와 MySQL 데이터는 ZIP에 포함하지 않으므로 기존 설정과 데이터 볼륨을 유지할 수 있습니다.

```bash
docker compose up -d --build
```

새 DB 테이블은 추가하지 않으므로 별도 수동 마이그레이션은 필요 없습니다.
업데이트 이후 생성한 방부터 새 설정과 정확한 인원 시작 조건이 적용됩니다.
업데이트 전 생성한 방은 기존 조건(4명 이상 시작, 실제 인원 기준 기본 역할 배정)을 유지합니다.
새 기능을 사용하려면 기존 방을 나가 새 방을 만드세요.
